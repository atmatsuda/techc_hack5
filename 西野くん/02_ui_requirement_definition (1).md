# [AI翻訳チャット＋通話アプリ（仮）] 画面フロントエンド・UI要件定義書

## 1. システム概要（画面モックアップ）
- **目的・UIコンセプト：** AI翻訳付きチャット・通話モックアップUIの作成
- **動作環境：** ブラウザ環境、Tailwind CSS(CDN版)

## 2. 画面機能要件（今回実装・デザインするモック対象）
- [x] ホーム画面（チャット一覧・設定・新規チャット） [難易度：レベル2 - 基本]
- [x] チャット画面（吹き出し単位翻訳制御） [難易度：レベル3 - 実務標準]
- [x] 通話ルーム（画面切り替えモック） [難易度：レベル3 - 実務標準]
- [x] 設定画面（Enter送信切り替え等） [難易度：レベル2 - 基本]

## 3. UI/UX・デザイン品質要件
- **デザイン・実装方針詳細：**
  1. Enter送信は初期ON、設定画面のトグルスイッチで変更可能とする。
  2. 翻訳は全体の自動翻訳ではなく、各吹き出しごとに個別に切り替え可能なUIにする。
  3. 通話中（モック画面表示中）もチャット履歴を薄く背景に透過させて確認できる設計。
  4. 通話開始は画面右下のFAB（フローティングアクションボタン）から呼び出し可能。
- **主要要素のID名（半角英数字統一）：**
  - 送信ボタン: `send-btn`
  - メッセージ入力欄: `chat-input`
  - チャット履歴エリア: `chat-area`
  - 通話開始ボタン: `call-btn`
  - 通話終了ボタン: `hangup-btn`

## 4. 今回スコープアウト（完全に対象外にした）機能
- **本物の通話システム（WebRTC等の接続）：** 難易度レベル5（実務発展）であり開発期間を超えるため、今回は本物の通話機能は見送り、通話中の画面デザインのみをモックアップとして作成する。
- **本番用の外部AI翻訳API連携：** 期間およびフロントエンド主体の実習であるため、JavaScript側の擬似データで制御する。
