# [AI翻訳チャット＋通話アプリ（仮）] 画面デザイン要望書

## 1. 全体デザイン方針
「言語の壁を感じず、誰でも直感的に交流できるシンプルなコミュニケーションUI」
- 初めて使う海外ユーザーでも迷わない、見慣れたSNS型チャットUIを採用。
- 翻訳機能は必要な時だけワンタップで利用可能にし、画面の複雑さを排除。
- 情報量を整理し、会話そのものに集中できる画面設計。

## 2. デザインテイスト
**採用スタイル：ミニマルホワイト**

| 用途 | カラーコード | 役割・視覚効果 |
| :--- | :--- | :--- |
| 背景 | #FFFFFF | 白背景で翻訳文やチャット内容の可読性を最優先にする。 |
| メインカラー | #2563EB | 操作可能なボタンや重要なUIを直感的に認識させるブルー。 |
| アクセント | #10B981 | オンライン状態（🟢）や成功状態をスマートに表現。 |
| 文字色 | #111827 | 高いコントラストを保ち、長文でも目が疲れにくいダークグレー。 |
| 補助背景 | #F8FAFC | 相手の吹き出しやアーカイブエリアを優しく区切る微彩色。 |

## 3. メイン画面構成（PC表示イメージ）
```text
┌────────────────┬──────────────────────────────────────┐
│ アーカイブ一覧  │ 相手情報（Alex / 🟢 Online / 🇺🇸）     │
│────────────────│──────────────────────────────────────│
│ 検索           │                                      │
│ 過去会話リスト  │ チャット履歴表示エリア               │
│                │ （スクロール可能）                   │
│                │                                      │
│                │──────────────────────────────────────│
│                │ [翻訳スイッチ] [入力欄] [送信] [通話] │
└────────────────┴──────────────────────┘
```

## 4. チャット画面UI要素
### ① ヘッダー
- 配置要素：プロフィール画像、相手の名前、オンライン状態、使用言語、通話ボタン
- 表示例：👤 Alex 🟢 Online 🇺🇸 English

### ② チャット吹き出し（一般的SNS型）
- 自分（右寄せ）：
  ```text
          ┌──────────┐
          │ Hello!   │
          └──────────┘
  ```
- 相手（左寄せ）：
  ```text
  ┌──────────┐
  │ Hi!      │
  └──────────┘
  ```

## 5. 主要機能の画面挙動
- **翻訳切り替え：** 翻訳表示ボタンを押下すると翻訳文を展開。再押下で原文表示に戻る。
- **アーカイブ整理：** 日付別整理、会話カテゴリ、検索機能を持つサイドバー。
- **通話機能：** 実際の音声通信ではなく画面モック。ボタン押下で通話中画面へ切り替える。
